# 鼠环 · MouseRing 1.0 Preview

为 Mac 提供可自定义圆环、鼠标按键、原生捏合缩放、滚轮学习和平滑滚动的原生工具。

本项目为预览版，当前构建面向 **Apple Silicon / macOS 27 及以上**。使用 AppKit、CoreGraphics、Core Audio 和 IOKit，不需要 Electron 或外部滚动进程。

![平滑滚动设置](Media/smooth-scrolling.png)

## 可以做什么

- **圆环**：八个位置、二级菜单、自定义名称、快捷键和图标；直接点击圆环编辑。透明扇区同样可以选中动作，超出外边界点击收起。
- **自定义鼠标键**：按实际检测的按键编号设置单击、按住＋滚轮、按住＋移动；中键显示为“按键 3（中键）”。各动作可独立反向。
- **原生缩放**：按住选定鼠标键再滚动，发送 macOS 捏合手势，不使用键盘缩放替代。
- **滚轮学习**：分别保存应用外的缩放手感与圆环内的音量／亮度步进；侧滚轮不参与学习。
- **平滑滚动**：独立有限轨迹引擎；调整滚动距离、过渡时长、加速倍率、垂直／水平反转，按住控制键可加速、转横向或暂停平滑。按应用设置，支持仅列表生效。
- **亮度**：硬件调节优先，低于硬件下限时缩放显示器原始色彩表，逻辑亮度可到画面全黑；没有黑色遮罩。数字 0% 不代表背光功率或实测亮度归零。

## 安装与使用

从 Release 下载 `MouseRing-1.0-Preview-macOS.zip`，解压后将“鼠环 Preview.app”放入“应用程序”。这是本地临时签名构建，尚未经过 Apple Developer ID 签名或公证；请只安装你信任来源的构建。

首次打开进入设置。需要在 macOS“隐私与安全性 → 辅助功能”中允许键鼠监听／发送。应用不会重置已有授权。先在“鼠标”里识别按键，再分配“打开圆环”及其他动作。圆环不支持键盘快捷键呼出。

关闭设置窗口或按 Command+Q 会隐藏界面和程序坞图标，后台仍运行；完全退出请使用菜单栏菜单。完全退出会恢复本程序持有的调暗色彩表。

预览版标识为 `local.mousering.preview`，配置与旧私人版本分开保存。为避免滚动被重复处理，使用本版平滑滚动前，请暂停其他鼠标滚动处理工具。不要同时运行两份鼠环并监听同一鼠标。

## 平滑滚动的调节

- **每格距离**：设置一单位普通滚轮行输入对应的目标像素数。不同鼠标或驱动可能每个物理刻度上报多行，这不是刻度校准器；缩放与圆环刻度校准另行保存。
- **过渡时长**：单位为毫秒；越短响应越紧，越长缓动越明显。默认 180 ms。
- **加速倍率**：仅在按住指定加速键时应用；未设置时不额外加速。
- 应用列表中的条目可以禁用、沿用全局或单独编辑。修改沿用全局条目的参数会创建独立手感。
- 平滑引擎只处理普通非连续滚轮事件；触控板和带原生阶段的连续输入保留原来的时序。独立缩放使用原生捏合手势，先于普通滚动处理。

本版采用五次多项式的累计轨迹差分。每次输入有有限结束时间，不依赖无限逼近的尾部，也不以固定的丢弃阈值结束；不同刷新率下保持目标距离。实现说明和来源边界见 [PROVENANCE.md](PROVENANCE.md)。

## 构建与测试

安装支持 macOS 27 SDK 的 Xcode Command Line Tools。构建脚本通过 `xcrun` 选择当前 SDK。

```sh
./build.sh
./test.sh
```

构建结果在 `dist/`；设置 `MOUSERING_OUTPUT_DIR` 可更换输出目录。测试包括独立轨迹与原生 NSScrollView、鼠标路由与捏合手势、录制拦截、亮度模型及异步回复、圆环与设置窗口回归。测试默认不发送全局输入，不改真实屏幕亮度，不持久化设置。`build.sh` 同时运行应用内模型自测。

宣传片工程在 `Promo/`。运行 `Promo/render.sh`，需要系统 Swift 编译器以及安装 numpy 的 Python。`PYTHON` 可指定 Python 路径。宣传画面是功能示意动画，非实机录屏；鼠标为原创示意绘图，无厂商产品图或品牌标志。

## 预览版边界

- 原生捏合、DDC、色彩表及某些系统事件使用未公开接口或设备相关行为，系统更新可能改变兼容性。尚不面向 Mac App Store。
- 缩放由目标应用支持决定。本版保留此前已在 Chrome 和 Word 中工作的捏合路径；新构建尚未完成这两个应用的物理滚轮实测。
- 外接显示器是否支持硬件亮度取决于型号、连接和显示模式。可使用已运行的 BetterDisplay 的本地通知接口；BetterDisplay 不随本项目分发。
- 全黑需要色彩表可用，某些 HDR／镜像／驱动配置可能拒绝或覆盖它。逻辑百分比不等同实测 nits。
- 从其他版本导出的平滑滚动配置不会转换为旧第三方格式；本预览版不导入第三方滚动配置。
